# Milo Signals 🤖

ИИ-бот, который превращает сырые сообщения из телеграм-каналов с сигналами («заряжайте наверх», скриншоты позиций и т.п.) в чистые сигналы формата **Cornix**, чтобы сделки автоматически открывались на **Bybit**.

Работает на **Cloudflare Workers** — бесплатно, без карты, без сервера, настраивается **полностью с айфона**.

## Как это работает

```
Каналы с сигналами
   ↓ (auto-forward bot — у тебя уже настроен)
Твой канал-агрегатор  ←  бот Milo (админ, читает всё)
   ↓ ИИ (OpenRouter): понимает контекст, сленг и скриншоты
НОВЫЙ чистый канал (только формат Cornix)  ←  Cornix (админ)
   ↓
Bybit
```

**Важно:** Cornix нужно подключить к **новому чистому каналу**, а не к агрегатору. Тогда Cornix видит только идеальные сигналы.

Что умеет бот:
- Помнит последние ~15 сообщений каждого канала — понимает «заряжайте наверх» после поста про SOL.
- Читает **скриншоты** позиций (символ, направление, цена входа, плечо).
- Вход «по рынку» — сам подставляет текущую цену с Bybit.
- Обновления сделок: «фиксируем», «стоп в бу», «отмена» → отправляет Cornix команду реплаем на исходный сигнал (`Close 50%`, `Move Stop-Loss to Entry`, `Cancel`).
- Никогда не выдумывает цены: если в источнике нет стопа/тейков — их не будет и в сигнале.
- Сомнительные сигналы и сигналы без стоп-лосса не публикует, а присылает **тебе в личку** на проверку.

## Установка (с айфона, ~20 минут)

### Шаг 1. Создай бота
1. В Telegram открой **@BotFather** → `/newbot` → придумай имя и username.
2. Сохрани **токен** (`123456:ABC-DEF...`).

### Шаг 2. Создай чистый канал
1. Создай новый **приватный канал** в Telegram (например «Milo Clean Signals»).
2. Добавь туда своего бота **администратором** (право публиковать сообщения).
3. Добавь туда же **Cornix бота** администратором и подключи канал на сайте Cornix (как ты уже делал), привязав к нему свой Bybit.
4. В настройках Cornix для этого канала задай дефолтные значения (размер позиции, плечо; желательно и дефолтный стоп-лосс).

### Шаг 3. Добавь бота в канал-агрегатор
Добавь своего бота **администратором** в канал, куда auto-forwarder пересылает сигналы (права на чтение достаточно, «Post messages» нужно только чтобы работала команда `/id`).

### Шаг 4. OpenRouter
1. Зайди на [openrouter.ai](https://openrouter.ai), пополни на $5.
2. Создай API-ключ (Keys → Create Key). Сохрани его.

$5 хватит на **тысячи** сообщений с моделью по умолчанию (`google/gemini-2.5-flash`).

### Шаг 5. Cloudflare
1. Зарегистрируйся на [dash.cloudflare.com](https://dash.cloudflare.com) (бесплатно, карта не нужна).
2. **Storage & Databases → KV** → Create namespace → назови `milo-kv` → скопируй его **ID**.
3. На GitHub открой файл `wrangler.jsonc` этого репозитория → карандаш (Edit) → замени `REPLACE_WITH_YOUR_KV_NAMESPACE_ID` на свой ID → Commit.
4. В Cloudflare: **Workers & Pages → Create → Import a repository** → подключи GitHub → выбери репозиторий `Milo-Signals` → Deploy. (Build command оставь по умолчанию: `npx wrangler deploy`.)
5. После деплоя открой воркер → **Settings → Variables and Secrets** и добавь:

| Имя | Тип | Значение |
|---|---|---|
| `BOT_TOKEN` | Secret | токен от BotFather |
| `OPENROUTER_API_KEY` | Secret | ключ OpenRouter |
| `WEBHOOK_SECRET` | Secret | любая длинная случайная строка (20+ символов) |
| `SOURCE_CHANNEL_IDS` | Text | пока оставь пустым — заполним на шаге 7 |
| `TARGET_CHANNEL_ID` | Text | пока пустым |
| `ADMIN_CHAT_ID` | Text | пока пустым |

Сохрани (воркер передеплоится сам).

### Шаг 6. Включи webhook
Открой в Safari (подставь свои значения):

```
https://<имя-воркера>.<твой-сабдомен>.workers.dev/setup?secret=<WEBHOOK_SECRET>
```

Адрес воркера виден на его странице в Cloudflare. Должно вернуть `"ok": true`.

### Шаг 7. Узнай ID каналов
1. В канале-агрегаторе отправь сообщение `/id` — бот ответит `Chat ID: -100...`.
2. В чистом канале отправь `/id` — получи второй ID.
3. Напиши боту **в личку** `/start`, потом `/id` — получи свой личный ID.
4. Вернись в Cloudflare → Variables and Secrets и заполни:
   - `SOURCE_CHANNEL_IDS` = ID агрегатора (можно несколько через запятую)
   - `TARGET_CHANNEL_ID` = ID чистого канала
   - `ADMIN_CHAT_ID` = твой личный ID

### Шаг 8. Тест
Напиши в канал-агрегатор что-то вроде:

```
BTC лонг, вход 95000-94000, цели 97000 и 99000, стоп 92500, плечо 10х
```

Через несколько секунд в чистом канале должен появиться сигнал в формате Cornix. Потом проверь «понимание контекста»: напиши пост про какую-нибудь монету, а следом «заряжаем наверх, стоп 5% ниже» — бот должен связать их.

**Обязательно погоняй неделю-две на Cornix Paper Trading (виртуальный счёт), прежде чем подключать реальные деньги.**

## Настройки

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `MODEL` | `google/gemini-2.5-flash` | Модель OpenRouter (нужна поддержка изображений) |
| `MIN_CONFIDENCE` | `0.65` | Ниже этой уверенности сигнал идёт тебе в личку, а не в канал |
| `REQUIRE_SL` | `true` | Не публиковать сигналы без стоп-лосса (они идут в личку). Поставь `false`, если настроил дефолтный SL в Cornix |
| `HISTORY_SIZE` | `15` | Сколько сообщений канала бот помнит |

## Если что-то не работает

- **Бот не отвечает на `/id`** — проверь, что он админ канала и что `/setup` вернул `ok: true`. Логи: страница воркера → Logs → Live.
- **Сигнал не появился в чистом канале** — посмотри личку: бот шлёт туда причину (низкая уверенность, нет стопа, ошибка).
- **Cornix не открывает сделку** — проверь настройки канала на сайте Cornix (биржа ByBit, включён авто-трейдинг, задан размер позиции).

## ⚠️ Честно о рисках

- Слепое копирование чужих сигналов с плечом — это способ быстро потерять депозит, а не разбогатеть. Начни с paper trading и микро-сумм.
- ИИ может ошибиться в интерпретации расплывчатого сообщения. Именно поэтому сомнительные сигналы идут тебе на ручную проверку.
- Почти все prop-фирмы **прямо запрещают** копитрейдинг и сторонние сигналы — за это отбирают аккаунт без выплат. Прочитай правила фирмы до того, как подключать эту схему.
